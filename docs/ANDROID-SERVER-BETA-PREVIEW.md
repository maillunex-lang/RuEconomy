# RussiaEconomicMMO: Android + сервер, beta-preview 0.1

Дата сборки: 2026-11-17.

## Доступ

- Android APK (debug, подписан тестовым ключом): https://rikagro.ru/russia-mmo/android.apk
- Проверка сервера: https://rikagro.ru/russia-mmo/health
- API каталога: https://rikagro.ru/russia-mmo/api/catalog
- Сервис: `russia-economic-mmo.service`, отдельный loopback 127.0.0.1:18783
- Nginx: отдельный HTTPS-префикс `/russia-mmo/` и ограничение частоты запросов авторизации
- Каталог: 300 товаров, 450 рецептов, 45 типов предприятий, 10 городов

## Что работает

- Регистрация, вход, токен сессии (хэш в SQLite), сохранение входа на Android.
- Горизонтальный Godot 4.7.2 клиент, адаптивный текстовый интерфейс.
- Каталог строительства: карточка предприятия, назначение, стоимость, «Назад» и «Строить».
- Выбор города с приоритетом городов, где уже есть здания.
- После выбора города: схематичная 2D-сетка 24×16 для размещения; занятые клетки недоступны.
- Транзакционная покупка участка/постройка, идемпотентность повторной операции.
- Склад, ограниченный импорт первичных материалов, рецепты совместимых производственных предприятий, производство одной партии с реальным списанием сырья, денег и учётом результата.
- SQLite-хранилище в изолированной директории `runtime/`.

## Проверки

- 38 тестов экономического ядра успешно.
- Проверены серверные регистрация, вход, строительство, повтор операции, карта и рецепты на временной копии SQLite.
- Godot headless запустил сцену без ошибок; Android APK экспортирован, подпись подтверждена apksigner.
- Nginx -t успешен, публичные HTTPS health и APK проверены.
- Реальный Android UI/управление на смартфоне **не тестировались**.

## Что пока НЕ готово до полноценной беты

Это **beta-preview / функциональная альфа**, а не завершённая экономическая MMO. Текущий сервер не запускает непрерывную экономику с 100 ИИ-компаниями, не обрабатывает реальный онлайн-рынок через клиент и не поддерживает торговые UI, налоги, логистику, модернизацию, банкротства, выбор участка по типу земли, размеры зданий и полнофункциональные магазины.

45 типов зданий можно разместить, но реальные производственные рецепты есть только у типов, связанных с каталогом. Здания без рецептов пока выполняют роль объектов компании. Схематичная карта не является 3D-картой городов. В интерфейсе пока нет полноценного дизайна всех экранов релизного качества.

Серверные игровые сутки сейчас не продвигаются автоматически. Начальный баланс при регистрации 100 000 ₽ является тестовым; стоимость строительства 2 500 ₽ условная и одинакова для всех типов. Для коммерческого релиза нужны тарифы, юридические документы, защита от злоупотреблений и нагрузочное тестирование.

## Размещение и безопасность

Другие приложения и их конфигурации не изменялись, кроме минимального подключения отдельного Nginx snippet к общему HTTPS virtual host. До изменения сохранена копия `deploy/nginx-before-russia-mmo.conf`. API слушает только localhost, клиент работает по HTTPS. Сервис ограничен 256 MB RAM. Приватные ключи не копировались в проект. APK подписан **debug-ключом**, не production release key.

Возможность возврата: остановить `russia-economic-mmo.service`, убрать include snippet и выполнить `nginx -t && systemctl reload nginx`, не затрагивая другие сервисы.
