# Production Catalog 1.0 — QA

## Структурная проверка: PASS

- 300 SKU; 450 уникальных фиксированных рецептов; 45 предприятий; 70 типов линий.
- 233 выпускаемых SKU: 217 имеют по два рецепта и 16 по одному.
- 67 SKU поставляются через сельское хозяйство, добычу, возврат вторсырья, коммунальные услуги либо ограниченный импорт.
- Проверены ссылки всех входов/выходов, положительные целые количества, привязки к линиям.
- Нет циклов, каждый вход имеет первичный источник; масса входа не меньше массы выхода в упрощённой модели.
- Исторический черновик 45 рецептов отправлен в docs/archive, не участвует в актуальной модели.

## НЕ подтверждено
- Отраслевые нормы, точные балансы химических реакций, цены, рентабельность, мощность производств, лицензии, сезонность и импортные квоты.
- Масса и затраты являются тестовыми игровыми коэффициентами; не использовать в промышленности.
- Статус для реализации на сервере: НЕ ГОТОВО без Technology Calibration / Economy Balancing.
