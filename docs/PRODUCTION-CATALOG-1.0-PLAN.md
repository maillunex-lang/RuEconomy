# Production Catalog 1.0 — текущий план

Структурная проектная спецификация составлена: 300 SKU, 450 рецептов, 45 типов предприятий, 70 типов линий.
Данные: GOODS.json/csv, RECIPES.json/csv, EQUIPMENT.json, COMPLETE.md.
Далее отдельный этап: экспертная проверка коэффициентов и отходов, себестоимости, мощностей, спроса и импортных ограничений.
До неё нельзя объявлять технологический или экономический баланс завершённым.
