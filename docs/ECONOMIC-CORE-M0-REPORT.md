# Economic Core M0 — отчёт реализации

Дата: 2026-11-17.

## Что реализовано

Изолированная библиотека Python + SQLite в `core/economy.py`. Данные каталога читаются из существующих JSON без изменения исходных файлов.

- 300 SKU и 450 фиксированных рецептов.
- Компании и отдельные денежные счета в целых копейках.
- Идемпотентные операции импорта, производства, торговли и исполнения контрактов.
- Транзакционные денежные переводы и движение складских партий; FIFO/FEFO-упорядоченное списание.
- Производство с реальным расходом входных SKU, электроэнергии и труда в рамках условных тарифов.
- Предприятия, привязка типа предприятия к рецепту и дневное ограничение числа партий.
- Контракты между компаниями, их однократное исполнение.
- Игровые сутки, журнал операций и сохранение SQLite при указании пути к файлу.
- Поставщик первичных ресурсов с лимитом на отдельную операцию импорта.

## Проверки

17 автоматических тестов пройдены, включая пробное производство по всем 450 рецептам, атомарность, запрет перерасхода товара и денег, идемпотентность, исполнение контрактов, ограничения мощности, цепочку ржаного хлеба.

Запуск проверок:

`cd /home/gamedev/projects/RussiaEconomicMMO && python3 -m unittest discover -s tests -v`

Пересчёт Economy Balancing 1.1:

`cd /home/gamedev/projects/RussiaEconomicMMO && python3 core/balance.py`

## Ограничения M0

Это **локальное экономическое ядро**, а не работающий публичный MMO-сервер. Отсутствуют HTTP API, аутентификация, многопользовательская конкурентность и PostgreSQL; нет работающего Android-клиента.

Пока нет полноценного автоматического рынка, графика торговых заявок, ежедневных лимитов импорта по городам, сроков доставки, складских лимитов, начисления налогов, зарплатного рынка, кредитов, сезонности, R&D, 100 ИИ-компаний и модели спроса 10 городов. Ввод начального капитала в тестах является явным созданием начального баланса, не финансовой эмиссией работающего сервера.

Численные нормы исходного каталога условны; расчёты Economy Balancing 1.1 не гарантируют реалистичную рентабельность.
